# 慈善捐款系统

面向本地毕业设计和课程演示的前后端分离项目。**第一版五个实施阶段已完成**，可演示“管理员发布项目 → 用户模拟捐款 → 用户和管理员查询记录 → 统计一致”的业务闭环，最终运行、演示和验收材料已整理。

| 目录 | 内容 |
| --- | --- |
| `frontend/` | Vue 3、Vite、Vue Router、Element Plus、Axios；账号认证、项目浏览与进度、模拟捐款、个人记录、管理与统计页面 |
| `backend/` | Java 17、Spring Boot 2.7.18、JPA、Spring Security；Session、CSRF、项目管理、捐款事务与幂等、记录和金额汇总 |
| `database/` | MySQL 8.4 三张表与独立演示项目脚本 |
| `docs/` | 运行方法、已实现接口、验证记录 |

首次使用从 [最终交付说明](docs/最终交付说明.md) 开始；启动时按 [运行说明](docs/运行说明.md) 配置数据库环境变量并分别启动后端和前端。数据库密码和演示管理员密码均不保存在源码中。

前端现已改为面向公众的公益展示：首页呈现项目与初心，支持项目筛选、搜索和响应式浏览。当前仍未接入真实支付，提交前明确提示只生成参与记录，不扣款。改版范围见 [前端展示优化](docs/前端展示优化.md)。
