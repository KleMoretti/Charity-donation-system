# 慈善捐款系统

面向本地毕业设计和课程演示的前后端分离项目。目前已完成**第四阶段：模拟捐款与统计**，可演示“管理员发布项目 → 用户模拟捐款 → 用户和管理员查询记录 → 统计一致”的业务闭环。

| 目录 | 内容 |
| --- | --- |
| `frontend/` | Vue 3、Vite、Vue Router、Element Plus、Axios；账号认证、项目浏览与进度、模拟捐款、个人记录、管理与统计页面 |
| `backend/` | Java 17、Spring Boot 2.7.18、JPA、Spring Security；Session、CSRF、项目管理、捐款事务与幂等、记录和金额汇总 |
| `database/` | MySQL 8.4 三张表与独立演示项目脚本 |
| `docs/` | 运行方法、已实现接口、验证记录 |

先阅读 [运行说明](docs/运行说明.md)，再按说明配置数据库环境变量、启动后端和前端。数据库密码和演示管理员密码均不保存在源码中。

前后端构建通过，已使用用户提供的 `backend/.env` 完成第四阶段真实 MySQL 浏览器主流程和代表性权限、金额、重复提交检查。该本机文件不纳入版本管理，启动时需将其中配置加载为进程环境变量，方法见运行说明。

管理员由环境变量控制的初始化流程创建，新注册用户固定为普通用户。捐款入口位于募集中项目详情；全部为模拟捐款，不扣款、不涉及实际资金到账。管理员通过后台管理导航访问全部记录和基础统计。
